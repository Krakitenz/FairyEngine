# FairyEngine

Небольшой 2D-движок/игровой прототип на C++20 с OpenGL.

## Требования

- Windows 10 или новее
- Visual Studio 2026 с workload **Desktop development with C++**
- Конфигурация **x64**

Внешние зависимости уже находятся в `FairyEngine/external`:

- GLFW 3.5.1
- GLAD
- GLM
- stb_image/stb_truetype

## Сборка

1. Открыть `FairyEngine.slnx` в Visual Studio.
2. Выбрать конфигурацию `Debug` или `Release` и платформу `x64`.
3. Выполнить **Build → Build Solution**.
4. Запустить проект через Visual Studio.

Ресурсы игры находятся в `FairyEngine/assets` и должны сохранять эту структуру относительно исполняемого файла/рабочей директории.

## Управление

- **A / D** — движение влево и вправо;
- **Space** — прыжок;
- **левая кнопка мыши** — взаимодействие с меню и дверью.

## Структура проекта

- `FairyEngine/src/core` — базовые системы движка;
- `FairyEngine/src/world` — мир, локации и переходы;
- `FairyEngine/src/ui` — пользовательский интерфейс и текст;
- `FairyEngine/assets` — шейдеры, шрифты и описания локаций;
- `FairyEngine/external` — сторонние зависимости.

## Лицензии

Перед публичной публикацией нужно проверить права на шрифты в `FairyEngine/assets` и сохранить лицензии сторонних библиотек, если они требуются их авторами.
